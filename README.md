# html-dump

A dumping ground for standalone HTML files I make, mostly LLM-generated —
explainers, small tools, one-off reports. The point is just to have a place
where I can drop a self-contained `.html` file and then view or share it from
any device via a URL, instead of emailing myself files or digging through
local folders.

`index.html` lists all the files in the repo. It's generated by
`generate_index.sh`, which should be re-run after adding or removing a file:

```sh
./generate_index.sh
```
